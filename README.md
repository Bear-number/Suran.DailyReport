# Suran.DailyReport

图片式群聊日报：拉群聊记录做统计，精选话题与金句，按角色口吻写点评，渲染成图片发回群里。

## 功能

- 按群生成日报，可手动触发或定时发送
- 图片模式出 png，文字模式出文字稿；可只预览不发群
- 统计发言量、活跃时段与成员排行
- 精选话题与金句，按角色口吻写总评与逐条短评
- 定时：开关、时间、补发窗口可配
- 每群独立冷却，避免重复生成
- 状态查询与重置：看冷却与各群发送记录，清掉记录重新生成

## 安装

先装依赖：`Alife.Function.FunctionCaller`。

装法二选一：插件市场里搜 `Suran.DailyReport`；或把目录放到 `Storage/Plugins/Suran.DailyReport/`，重启角色生效。

## 配置

在设置页里改，改完重启角色生效。

| 设置项 | 键 | 说明 | 默认 |
| --- | --- | --- | --- |
| 运行·功能文档常驻 | `DocumentAlwaysResident` | 开：功能说明常驻系统提示词，模型随时看得到工具；关：隐式加载省 token，模型先输出入口标签再读文档。日报多是主人明确要求或定时触发，默认关 | `false` |
| 基础·协议端地址 | `OneBotWsUrl` | 留空 = 自动跟随「QQ 聊天」插件的配置（推荐）。填了就用这里的，例如 ws://127.0.0.1:3001 | `""` |
| 基础·访问令牌 | `OneBotToken` | 与协议端配置的 token 一致。留空 = 跟随「QQ 聊天」插件。填了地址却没填这里，协议端一开 token 就会连不上 | `""` |
| 基础·协议端类型 | `ApiProvider` | 协议端类型，auto 自动识别，也可指定 napcat / llonebot / snowluma。 | `"auto"` |
| 基础·指定机器人昵称 | `BotNickname` | 锐评署名，留空自动获取Bot昵称 | `""` |
| 基础·可使用日报的群组 | `EnabledGroups` | 群号英文逗号分隔，留空=所有群 | `""` |
| 基础·定时排除的群组 | `DisabledGroups` | 群号英文逗号分隔，这些群不参与定时自动生成（不影响手动生成） | `""` |
| 基础·定时开启日报的群组 | `ScheduledGroups` | 群号英文逗号分隔，留空=与可使用群组一致 | `""` |
| 基础·详细日志 | `DetailLog` | 开启后输出拉取/统计/渲染的调试日志 | `false` |
| 分析·分析天数 | `AnalysisDays` | 日报分析最近几天的消息 | `1` |
| 分析·单次最大分析消息数 | `MaxMessages` | 最多拉取的消息条数，防止消耗过大 | `1000` |
| 分析·提示词字符预算 | `PromptMaxChars` | 群聊记录拼进提示词的最大字符数；超出时优先丢最老的消息，防止上下文超限被模型拒答 | `20000` |
| 分析·最小消息数阈值 | `MinMessages` | 少于该值不生成日报 | `10` |
| 分析·启用自动日报 | `EnableAutoReport` | 开启后每天在指定时间自动生成 | `true` |
| 分析·自动分析时间 | `AutoReportTime` | 每天自动生成日报的时间，格式 HH:mm，默认 23:59 | `"23:59"` |
| 分析·定时补发窗口(分钟) | `AutoReportCatchUpMinutes` | 到点没发成（进程重启、模型失败）时，在这个窗口内继续补发；超过窗口就等下一次定时。0 = 只在到点那一刻发 | `180` |
| 分析·活跃时段窗口(分钟) | `ActiveWindowMinutes` | 滑动窗口统计最活跃时段的窗口宽度 | `90` |
| 分析·时间范围口径 | `AnalysisWindowMode` | rolling=最近 N 天滚动窗口；naturalDay=按自然日（定时按到点那天、手动按今天算） | `"rolling"` |
| 内容·启用AI锐评 | `EnableComment` | 日报末尾增加人设风格的点评 | `true` |
| 内容·启用锐评改写 | `EnableCommentRewrite` | 总评写成「一半人…另一半人…」这类模板时，再调一次模型改写；关掉则保留原句，省一次调用 | `true` |
| 内容·锐评读角色人设 | `PersonaFromCharacter` | 关掉就不注入角色人设，锐评只按通用要求写 | `true` |
| 内容·锐评人设只取语气段 | `PersonaStyleOnly` | 只截取人设里讲口癖和句式的那一节；关掉则用整段 | `true` |
| 内容·锐评人设字数上限 | `PersonaMaxChars` | 注入的人设最多多少字，0 = 不限 | `4000` |
| 内容·锐评风格（手填） | `CommentStyle` | 额外写一句想要的锐评口吻，追加在人设后面；留空就只用角色人设 | `""` |
| 内容·最少话题数 | `MinTopics` | 话题不足时显示问号占位 | `1` |
| 内容·最多话题数 | `MaxTopics` | 最多展示的话题数 | `5` |
| 内容·金句数量 | `QuoteCount` | 展示的金句数，0为不展示 | `3` |
| 内容·活跃用户数量 | `TopUserCount` | 展示的活跃用户数 | `10` |
| 权限·调用冷却时间(小时) | `CooldownHours` | 同一群两次日报的最小间隔 | `4` |
| 权限·白名单用户 | `WhitelistUsers` | QQ号英文逗号分隔，不受冷却限制（受豁免开关控制） | `""` |
| 权限·白名单豁免冷却 | `WhitelistExemptCooldown` | 关闭后白名单用户也受冷却限制 | `true` |
| 输出·输出格式 | `OutputFormat` | image=图片（需要系统装有Edge或Chrome）/ text=纯文本 | `"image"` |
| 输出·日报主题风格 | `Theme` | warm暖黄 / sakura樱花粉 / clover幸运草绿 / diamond钻石黑 / sky天空蓝 / random随机 | `"warm"` |
| 输出·裁掉图片底部空白 | `CropBottomBlank` | 无头浏览器只能按窗口高度截图，估算富余会变成图底部的空白。开着会在截图后从下往上找到最后一行有内容的像素并裁掉多余部分；裁失败就用原图，不影响发送 | `true` |
| 输出·浏览器可执行文件 | `BrowserPath` | 无头截图用的 Edge/Chrome 完整路径，留空自动探测 | `""` |
| 输出·保留最近几份日报文件 | `ReportKeepCount` | 每次生成都往存储目录写一份 .html 与 .png。这里是最多保留的「份数」（一份=同批的 html+png），超出的按时间老的删；0=不清理 | `30` |
